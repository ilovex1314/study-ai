# 应用级课程侧栏设计

## 目标

将桌面端课程目录改为页面布局中的常驻左侧栏，而不是覆盖正文的浮动组件。收起时，正文必须回收侧栏空间。

## 布局

- 桌面端（宽度至少 1025px）使用 `lesson-layout` 的 CSS Grid：展开为 `220px minmax(0, 1fr)`，收起为 `44px minmax(0, 1fr)`。
- 侧栏位于布局第一列，使用 `position: sticky` 固定在视口内，不使用 `position: fixed`、`left` 或 `transform` 定位。
- 页面外层不预留 `padding-left`；正文宽度完全由 Grid 的第二列决定。
- 移动端保留现有的底部目录触发方式，避免在窄屏中压缩阅读宽度。

## 交互与视觉

- 收起按钮使用固定 `24 × 24` viewBox 的内联 SVG chevron，而不是字符箭头；按钮尺寸固定，禁止继承会拉伸图标的排版规则。
- 展开状态展示“课程目录”、课程列表和当前课程标记；收起状态只展示 44px 宽的图标轨道。
- 按钮应具备可见的键盘焦点态、`aria-expanded` 和清晰的 `aria-label`。
- 收起和展开仅过渡布局列宽/可见性，时长约 180ms，并尊重 `prefers-reduced-motion`。

## 验收

1. 在桌面端，目录不会覆盖课程正文或顶部章节导航。
2. 点击收起后，正文左缘移动到 44px 轨道之后；点击展开后恢复到 220px。
3. Chevron 始终保持正确比例、居中且不变形。
4. 在 1024px 及以下，课程目录仍可从移动端触发器展开。
5. 行为测试覆盖桌面端的初始展开、按钮切换和无障碍状态更新。
