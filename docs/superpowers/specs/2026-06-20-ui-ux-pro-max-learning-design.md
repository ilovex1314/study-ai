# UI/UX Pro Max 学习单元与视觉改造设计

## 目标

为现有 AI 工程学习系列增加 Day 13「UI/UX Pro Max 实战」，让学习者能解释 Skill 的原理与数据链路，能用命令生成设计系统、检索补充规则、把结果转成可验证的 UI 改动；同时把互动课程页面本身改造成这套流程的范例。

## 学习体验

Day 13 沿用现有的系列入口、概念、决策框架、练习和复盘结构。四个概念模块依次覆盖：结构化设计数据、五域检索、规则聚合与设计系统、实施和验收。架构图表达 `需求 -> 多域 CSV -> 检索/排序 -> 设计系统 -> token/组件 -> 可访问性验收 -> 反馈`，让输入、处理、输出及迭代回路可见。

## 视觉系统

课程定位为高专注度的开发者学习工作台。使用深石墨背景、靛蓝主色、薄荷绿进度色、暖琥珀行动色和阅读友好的无衬线字体。视觉不采用搜索结果里的 Cyberpunk 表层风格；它保留「沉浸式互动」的信息层级，但选择更适合长时阅读、更容易达到可访问性对比度的 editorial/workbench 变体。

页面通过 CSS 设计令牌统一颜色、间距、圆角、阴影、动效与焦点态；导航和卡片在 375/768/1024/1440 宽度下重排；固定底栏保留内容安全间距；所有动效在 `prefers-reduced-motion` 下关闭或缩短。

## 验收

- Day 13 可从系列入口和底栏到达，路由、概念、图解、至少四道题和复盘均可用。
- 每道题关联的概念都存在；系列连续扩展至 Day13。
- 页面通过 build 和现有逻辑测试；新增测试覆盖 Day13 数据与入口。
- 文档含原理、数据链路、命令、反例、实践任务和来源。
