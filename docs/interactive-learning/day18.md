## 目标

交付一张责任边界图、数据契约、权限矩阵和可跟踪风险清单。

## 核心概念

- 将客户端、服务、模型、检索、工具和人工控制面按责任划分。
- 数据契约定义 schema、来源、版本、敏感级别与保留期。
- 权限条件由身份与策略系统传递到检索和工具层。
- 风险条目包含影响、缓解、owner 与残余风险。

## 关系图

`用户/身份 → 服务边界 → 数据与检索 → 模型候选 → 策略/工具 → 审计证据`。

## 实践与复盘

为项目画六个责任边界；设计知识片段 JSON 契约，并写三个高风险项及其验收方式。
