## 目标

为模型、Prompt、检索和工具变更定义分级门禁、灰度、停止阈值与完整回滚包。

## 核心概念

- 风险等级由数据、权限与副作用影响面决定，不由代码行数决定。
- 灰度需要 cohort、对照和预先定义的质量、成本、安全阈值。
- 回滚同时覆盖代码、配置、模型路由、索引与 Prompt 版本。
- 红队反例是发布评审的一手证据。

## 关系图

`变更包 → 风险分级 → 离线评估/审批 → 小流量观察 → 扩大或停止 → 回滚与复测`。

## 实践与复盘

为一次 RAG 检索器升级写 5% 灰度方案、停止阈值和回滚 manifest；补两条权限反例。
